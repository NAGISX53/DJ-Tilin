# DJ Tilin

Bot dedicado únicamente a música.

1. Ejecuta iniciar.cmd; no necesitas dejar su ventana abierta.
2. En Discord, entra a voz y usa /play con una canción, artista o enlace YouTube/Spotify.
3. Usa /automix para cambiar normal, crossfade, smart o dj.
4. Abre ABRIR-PANEL.cmd para configurar las mezclas desde tu PC.
5. DETENER.cmd apaga el bot y el motor de audio.

Se conservan el ecualizador, la calidad adaptable, la cola y tus preferencias. Ya no ejecuta moderación, tickets, roles ni estadísticas. La carpeta sigue llamándose TILINbot para conservar los accesos existentes.


Puedes invitar DJ Tilin a otros servidores con el enlace de INVITAR-BOT.txt. Las colas y ajustes son independientes. Los administradores de cada servidor deben autorizar la instalación.

El reproductor se actualiza en un solo mensaje. Usa /reproductor desde voz para mostrarlo en otro canal de texto; los controles confirman en privado.

Para elegir entre distintas versiones, usa /buscar con canción/artista y el filtro opcional version. Elige una de las cinco coincidencias privadas para añadirla a la cola.
